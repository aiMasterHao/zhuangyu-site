# 庄誉官网（第一版复刻）

基于 `www.zhuangta-tech.com` 的栏目结构和视觉语言制作的独立静态站，目标公司为**浙江庄誉科技有限公司**。

## 本地预览

```bash
npm start
```

然后打开 <http://localhost:4173>。
